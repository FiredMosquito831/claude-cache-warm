Live sessions

Each session has its own timer. It starts when a turn ends and pings only after a full interval with no request at all; any prompt or turn restarts it. By default a session is warmed only while it waits on a subagent, background task or scheduled task. The right-hand columns are this session's own settings; "Inherit" uses its project, surface or global value.

Settings

Most specific wins: session > project folder > surface (CLI, Desktop app, IDE) > global > plugin tab > defaults. Anything left on "Inherit" falls through to the next scope down. Changes reach running sessions within seconds.
