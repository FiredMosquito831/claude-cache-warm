# Claude Cache Warm — desktop tray app

A thin [Tauri v2](https://v2.tauri.app) tray app. The dashboard
(`node dashboard/server.mjs`) is the real UI; this app only:

- shows a tray icon with **Open dashboard**, **Warming enabled** (check),
  **Interval** (Auto / 4 / 15 / 30 / 50 min) and **Quit**;
- edits `enabled` and `intervalMinutes` in `config.json` (atomic temp-file + rename,
  other keys preserved, created with contract defaults if missing);
- starts the dashboard server if `GET /api/health` doesn't answer, and kills it on
  quit only if it spawned it;
- shows the dashboard in a window (closing it hides to tray), single instance.

Shared paths and the HTTP API are defined in [`../docs/CONTRACT.md`](../docs/CONTRACT.md).

## Prerequisites

- Node.js 18+ (npm — do not use Bun) and `node` on `PATH` at runtime
- Rust stable (1.77.2+) with the MSVC toolchain, WebView2 (ships with Windows 11)

## Develop

```sh
cd desktop
npm install
npm run dev        # tauri dev
```

Rust-only type check: `cd src-tauri && cargo check`.

## Build

```sh
npm run build      # tauri build --config src-tauri/tauri.bundle.conf.json
```

`tauri.bundle.conf.json` adds `../../dashboard/` as the bundled resource `dashboard/`,
so installers ship the server. It is kept out of the base `tauri.conf.json` because
Tauri validates resource paths at compile time, which would break `cargo check` /
`tauri dev` whenever `dashboard/` is absent. Installers land in
`src-tauri/target/release/bundle/`.

## Environment variables

| Variable | Purpose |
| :--- | :--- |
| `CCW_HOME` | State dir (default `~/.claude-cache-warm/`) |
| `CCW_DASHBOARD_SERVER` | Absolute path to `server.mjs` (highest priority) |
| `CCW_NODE` | Node binary to use (default `node` from `PATH`) |

Server path resolution order: `CCW_DASHBOARD_SERVER` → bundled resource
`dashboard/server.mjs` → `dashboard/server.mjs` in any directory above the executable
(`<exe>/../dashboard/...`, and the repo root in dev) → `../../dashboard/server.mjs`
relative to the cargo manifest dir.

## Layout

```
package.json            @tauri-apps/cli, scripts dev / build / icon
app-icon.png            1024x1024 icon source (scripts/make-icon.py, needs Pillow)
ui/                     local fallback page: polls health every 1s, then redirects
src-tauri/
  tauri.conf.json       window "main" (hidden at start), CSP, bundle
  tauri.bundle.conf.json  release-only overlay: bundles ../../dashboard
  capabilities/default.json
  src/lib.rs            everything; src/main.rs just calls run()
  icons/                generated by `npm run icon`
```

## Security notes

The CSP applies to the local fallback page and allows `connect-src` to
`127.0.0.1` / `localhost`. The dashboard itself is loaded as ordinary remote web
content: no capability lists it under `remote.urls`, so it has no access to Tauri IPC.
