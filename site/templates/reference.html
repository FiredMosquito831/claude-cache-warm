01 Resolution

Most specific scope wins.

Each session resolves every setting from the first scope that defines it. Values that are unset simply inherit. Two scopes can never accidentally change each other's surfaces: inside a Claude Code session, an unscoped ccw change applies to that session's surface only.

sessionoverrides › project folderfolder and below › surfacecli · desktop · ide › globalmachine › plugin taboptions › defaultsin code 
# what this session actually uses, and where each value comes from
ccw config --session

# the same, for one scope
ccw config --desktop
ccw config --project

# every scope that currently holds a setting
ccw scopes
Surfaces come from the environment.

CLAUDE_CODE_ENTRYPOINT maps to cli; anything containing desktop to desktop; VS Code, JetBrains, Cursor and Windsurf entrypoints to ide. sdk-* runs — claude -p and the Agent SDK — are headless and are never registered or warmed.

03 Plugin tab

Those options in /plugin are a real scope.

Claude Code passes plugin-tab values to hooks as CLAUDE_PLUGIN_OPTION_*. The SessionStart hook snapshots them, so the CLI, status line and dashboard can see them too. Editing a value in the tab makes it win over the override it would otherwise sit behind; untouched tab values never undo edits made with ccw or the dashboard. Edits apply immediately through the ConfigChange hook, and sleeping timers pick them up within a minute.

The tab exposes one extra convenience option that is not a stored setting:

07 Scopes

Change one session, one folder, one surface, or everything.

ccw interval 30 --global              # every session
ccw when always --desktop             # every Desktop-app session
ccw off --cli                         # every CLI session
ccw interval 20 --project             # this folder and everything below it
ccw set maxIdleMinutes 600 --session  # just this session
ccw config --session                  # effective values and their sources
ccw reset --desktop                   # that scope inherits everything again
ccw unset intervalMinutes --project   # drop one key at one scope
An unscoped change is not global inside a session.

Run inside Claude Code, ccw off in the Desktop app turns off Desktop sessions, not your CLI ones. Changing every surface at once needs --global. From a plain terminal, unscoped means global.

Scope words for slash commands

session, project, cli, desktop, ide — for example /cache-warm:off desktop or /cache-warm:on session.

08 Cost

One cache read versus one cache write.

The plugin estimates each ping and each avoided rebuild from list prices in its own source. It is an estimate, not a bill — on a subscription the same tokens come out of usage limits.

Ping tokens × input price × cache-read multiplier

Cache reads are 0.1× base input price, except Fable and Mythos 5.1 at 0.025×.

Rebuild tokens × input price × write multiplier

Cache writes are 1.25× for a 5-minute cache and 2× for a 1-hour cache.

For the worked example on the overview — 800K tokens on Opus 5 with a 1-hour cache — the estimator reports roughly ${{ cost_example.ping }} per ping and ${{ cost_example.rebuild }} per cold rebuild, a break-even of about {{ cost_example.break_even }} pings. With a {{ defaults.maxIdleMinutes }}-minute idle cap, warming cannot continue indefinitely; with maxIdleMinutes at 0 a hard cap of {{ max_pings_per_idle }} pings per idle stretch still applies.

09 Limits

Bounds the code enforces.

  • Interval 1–59 minutes. It must stay shorter than the cache TTL; auto uses {{ auto_interval['5m'] }}m on a 5m cache and {{ auto_interval['1h'] }}m on a 1h cache. A fixed interval that is too long produces a warning in ccw status.
  • Idle cap. Pings stop after maxIdleMinutes with no human activity and no real work. 0 means no time cap.
  • Ping cap. At most ceil(maxIdleMinutes / interval) + 1 pings since the last activity. While background work is running, the idle cap and that formula do not apply, but the hard cap of {{ max_pings_per_idle }} pings since activity still does.
  • Background trust. Work reported by the last Stop is trusted for {{ work_trust_hours }} hours, so a completion notice that never arrives cannot warm forever.
  • Misses. {{ misses_before_suspend }} verified cache misses in a row suspend warming until someone is active again.
  • Expired cache. Never pinged: the ping would be the expensive rewrite.
  • Headless. claude -p and Agent SDK sessions are never registered.

Source of truth: scripts/lib.mjs. State files and the HTTP API are documented in docs/CONTRACT.md.
